# Map Readability Assessment System (MRAS)

## Version 1.1

MRAS produces continuous expert estimates of human bottom-up map readability.

Components:

* MRAS\_Overview.md
* MRAS\_Instructions.md
* MRAS\_ScientificBasis.md
* MRAS\_Calibration.md
* json\_schema.json

Workflow:

Input ZIP → MRAS\_Instructions → MRAS\_ScientificBasis → MRAS\_Calibration → Independent tile assessment → JSON validation → Batch JSON → Final validation.
